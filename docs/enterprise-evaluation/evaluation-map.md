# Coordinate a mutual action plan

[Track home](README.md) · [Scenario and templates](toolkit.md)

**Format:** Available reading lesson and manual practice. **Basis:** Original teaching synthesis using the named sources below. **Review:** Draft for editorial review; no professional certification.

## Understand

A mutual action plan is a jointly agreed set of milestones. A seller’s private close plan becomes mutual only when the buyer participates.

Give each milestone customer and vendor owners, a target date, dependency and completion evidence.

Run security, legal and procurement discovery early where possible; some steps depend on a finalized scope or approved data access.

Map technical selection, budget, risk approval, contract execution and implementation separately.

When a date slips, explain the consequence, agree a new date and preserve the decision history.

## See it in the fictional scenario

If procurement intake begins only after technical selection, show that dependency explicitly. Do not assume a signature can happen the same day as the readout.

## Try

Fill the MAP template with relative days. Make vendor onboarding a prerequisite for the purchase order and show which security tasks can start before the POC ends.

## Explain your decision

A seller sends a spreadsheet and hears nothing. Is the plan mutual?

1. Yes, because it was emailed
2. Not yet; customer owners and commitments need agreement
3. Yes, if all dates are this quarter

**Answer:** 2. Delivery of a document does not establish agreement. Confirm responsibilities and feasible dates.
