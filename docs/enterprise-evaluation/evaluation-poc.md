# Design and run a decision-ready POC

[Track home](README.md) · [Scenario and templates](toolkit.md)

**Format:** Available reading lesson and manual practice. **Basis:** Original teaching synthesis using the named sources below. **Review:** Draft for editorial review; no professional certification.

## Understand

A POC tests agreed uncertainty. Specify the sample, baseline, test method, threshold, owner and decision rule before starting.

Define in-scope and excluded sources, timebox, resources, stop conditions and changes requiring agreement.

Use pass, fail, inconclusive and not tested for results. Track activity status separately.

Measure agreed coverage and workflow usefulness, not simply the number of secrets discovered.

Run kickoff, checkpoints and a final readout. Capture blockers without exposing raw secrets or customer evidence in public templates.

Include cleanup and safe handling of sensitive findings even when the evaluation does not proceed.

## See it in the fictional scenario

A missing repository can fail the coverage target while making a separate performance test inconclusive. Results apply to individual criteria rather than one optimistic overall color.

## Try

Complete the POC scorecard and kickoff checklist. In the fictional result packet, one repository is unreachable: decide which criteria are failed versus inconclusive and whether a bounded retest is justified.

## Explain your decision

Nine of ten agreed repositories were scanned. Can you pass complete coverage?

1. Yes, round up
2. No; record the shortfall and investigate the blocker against the agreed rule
3. Yes, if many findings were discovered

**Answer:** 2. A finding count cannot compensate for an unmet coverage criterion. Use the declared rule and document what remains untested.

## Review your artifact

- Does it identify the decision and responsible owner?
- Can another person distinguish facts, assumptions and unknowns?
- Does each conclusion point to evidence or an explicit missing item?
- Have you documented an alternative and a condition that would change your recommendation?

Reading is **reviewed**; producing the artifact is **practiced**. A correct knowledge answer passes only that check. These are distinct from demonstrated workplace competence.
