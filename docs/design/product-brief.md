# Portfolio product brief (working draft)

## Problem
Current portfolio foregrounds independent technical systems and doesn't immediately establish Kristen's commercial leadership, team development, and GTM strategy experience. Visitors need clearer pathways to evaluate demonstrated professional results versus independently built projects.

## Positioning
Brand: **joy.** (visual signature); professional identity: **Kristen Joy Aing**.
**Commercial Leader. Curious Builder.**
**People first. Problem-driven. Systems-minded.**
This is not a software company named Joy. The private **Joy Index** must not be exposed publicly.

## Audiences, jobs and paths
1. Founder / Head-of-Sales hiring leader: Home → Work → relevant leadership case study → Contact.
2. Recruiter: Home → About / experience → credible achievements → Contact.
3. Product or technical collaborator: Home → Side Quests → project details, code/demo, decisions → Contact.
4. General visitor: Home → About → values/story or Side Quests.

These are hypotheses based on intended readers, not validated interviews.

## MVP scope
Must have:
- Five clear page destinations: Home, About, Work, Side Quests, Contact.
- Accessible responsive navigation; concise leadership-first homepage with evidence.
- Authentic short career story, values and leadership philosophy.
- At least two well-supported Work case studies; flag missing evidence as TBD rather than inventing.
- Side Quest listing with correct status, source links, lessons, limitations.
- Existing URLs preserved via redirects; metadata set for byjoyaing.com.
- Code review, lint, TypeScript, build and basic smoke tests.
Should have: richer project visuals, downloadable resume if current, social previews, light analytics.
Could have: notes section, animation, interactive timeline, CMS, backend. Defer until justified.

## Success criteria
Task-based: a tester can identify professional role, find a leadership example and navigate to Contact without guidance; another can find a Side Quest's status and linked repo.
Technical: no broken internal links; automated quality checks pass; keyboard-only navigation and mobile layout reviewed; no private or employer-confidential material.
Outcome signals (measure after launch, without inventing baselines): clicks to Work, Side Quests, Contact; qualitative feedback from a handful of actual target visitors.

## Non-goals
No public Joy Index, no new database or login, no fabricated business impact, no theme-heavy "Main Quest" navigation, no wholesale code rewrite.
