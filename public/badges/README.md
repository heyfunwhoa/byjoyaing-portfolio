## Display and claims

- Both files are the original 600 × 600 RGBA PNGs with true alpha transparency
  around the badge. Source files were copied unchanged; each contains 137,632
  fully transparent pixels. Preserve artwork, colors, proportions, and clear
  space; do not redraw, crop, recolor, overlay text, or combine marks.
- About serves the files locally at 80px square beside readable credential text.
  Empty alt text and an aria-hidden wrapper prevent duplicate announcements.
  Images add no link or keyboard stop. Credential rows stack on phones and use
  the existing two-column education grid from 640px.
- These are AWS Certified Cloud Practitioner and AWS Certified AI Practitioner,
  both Foundational. No Early Adopter designation, issue/expiry date, credential
  ID, personal verification URL, or claim of AWS endorsement is added.
- The existing public credential record and the owner's request establish the
  display scope. Keep certification claims current. Personal verification would
  require the owner's actual Credly credential URL; the issuer badge pages above
  are not personal verification links.
- AWS owns the marks; the repository's source license does not grant rights to
  them. Follow [AWS Brand Usage and Guidelines](https://aws.amazon.com/certification/policies/general-policies/)
  and [AWS digital badge guidance](https://aws.amazon.com/certification/certification-digital-badges/).
